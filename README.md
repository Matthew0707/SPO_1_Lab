# Лабораторная работа №1 — Метрики Холстеда

Программа для анализа исходного кода на языке **Python** и расчёта метрик Холстеда.

## Возможности

- загрузка `.py` файла;
- отображение исходного кода;
- выделение операторов и операндов;
- подсчёт частоты их использования;
- расчёт основных метрик Холстеда:
  - η1 — словарь операторов;
  - η2 — словарь операндов;
  - N1 — общее количество операторов;
  - N2 — общее количество операндов;
- расчёт производных метрик:
  - η — словарь программы;
  - N — длина программы;
  - V — объём программы;
- сохранение результатов анализа в CSV.

## Запуск

Приложение работает непосредственно в браузере и не требует установки дополнительных зависимостей.
